# Dawnielle's Day

A gentle guided planner and quiet space for navigating a day on your own terms.

## Current interaction model

- Check in with mood, energy, and free-form thoughts.
- Choose Gentle, Structured, or Mixed support.
- Set each part of the day independently.
- Add tasks/reminders with times.
- Keep recurring morning, night, and Friday reminders editable.
- Mark chosen directions done or say “not right now.”
- If a chosen structured reminder is missed, the app asks whether it should become optional instead of treating the miss as failure.
- Track deliveries only if useful.
- Pause/impulse buttons offer short grounding choices without analysis.
- Support choices provide a response without claiming to know what the user feels.
- Reflection questions rotate and save.
- Notes can be created and deleted.
- Settings can reset today or clear browser-saved data.

## Device priority

The UI is intentionally **iPhone 16 first**: 393px CSS viewport, safe-area padding, large touch targets, bottom navigation, short cards, and mobile-friendly modal sheets. Desktop remains supported.

## Privacy

This is a static GitHub Pages app. User-entered content is stored in the browser's `localStorage`; it is not written into the GitHub repository.
